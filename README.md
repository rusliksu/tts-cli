# tts-cli

`tts-cli` — планируемый read-only CLI для проверки сейвов и локального кэша
Tabletop Simulator. Основной потребитель — человек или AI-агент, которому нужен
стабильный машинно-читаемый отчёт без запуска игры и ручного обхода объектов.

## Статус

Репозиторий находится на стадии исследования и согласования пилота. Продуктовый
код, GitHub remote и лицензия ещё не добавлены.

## Первый сценарий

```text
tts assets audit <save.json> --offline --json
```

Команда должна найти структурированные ссылки на изображения, модели, PDF,
аудио и asset bundles, сопоставить их с кэшем TTS и вернуть доказуемый статус
для каждого ресурса.

## Границы безопасности

- Только чтение по умолчанию.
- Никаких скачиваний, удаления кэша и изменения сейвов в пилоте.
- `not_found_in_cache` не означает, что внешний URL сломан.
- Реальные Workshop-сейвы и игровые ассеты не входят в репозиторий.
